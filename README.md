# ММНВК

🔗 **[Live Demo](https://mnvk.vercel.app)**

## Опис проєкту

**ММНВК** Ресурс для Міжшкільного Навчального Комбінату, який надасть учням 10-11 класів можливість систематичного
вивчення лекційного матеріалу та проходження атестацій у обраній ними професії.

## Стек технологій

- **Основа:** React, Vite
- **Управління станом:** Redux Toolkit, Redux Persist
- **Стилізація:** Styled Components
- **Навігація:** React Router Dom
- **Бібліотеки npm:** ANTD, Framer Motion, Notiflix, React Loader Spinner, Modern Normalize, React Hook Form,
  ReactIcons, Lightbox
- **Робота з мережею:** Axios

## Як почати роботу

### 1. **Зклонуйте репозиторій:**

```bash
   git clone https://github.com/Dmytro1117/mnvk_react.git
```

### 2. **Встановіть залежності:**

```bash
   npm install
```

### 3. **Запустіть додаток:**

```bash
npm run start
```

Додаток буде доступний за адресою http://localhost:5173/
